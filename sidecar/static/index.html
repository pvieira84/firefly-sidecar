Firefly III

Server configuration

Set FIREFLY_URL and FIREFLY_TOKEN in your Docker environment, or mount a token using FIREFLY_TOKEN_FILE. Restart after changing configuration.

Your token is never returned to the browser.

Matching rules

Deposit and reimbursement totals may differ. Review the warning before applying; each selected split will be linked and have its pending tag removed.

Amazon Sync

Receive Amazon Spain orders directly from Chrome and review matching withdrawals.

Connect your browser

Set AMAZON_SYNC_TOKEN to a random secret of at least 32 characters in the sidecar environment and restart. Use this same token in the companion extension. Your Amazon login stays in Chrome.

Download Chrome extension · Extract the ZIP, open chrome://extensions, enable Developer mode and choose Load unpacked.

In the extension, enter this sidecar’s URL (including any subpath), the sync token and an account label. Open your Amazon.es order history and click Sync now. Optional daily sync runs while Chrome is open; Amazon may ask you to sign in again.

Enrichment appends order details to journal notes. Existing descriptions, splits, accounts, categories, tags and links are kept. Refunds and uncertain payment allocations require manual review.

Mark as Refund

Refunds may arrive in a different account, such as a gift card. Leave the account filter unchecked to include them.

Choose a withdrawal, then select its splits to refund. Split transactions can appear even when the whole total differs from the deposit. Tolerance is an absolute amount in the transaction currency.

Only selected withdrawal journals will be linked to this deposit using Refund. The deposit and selected journals are marked as cash; unselected splits are kept. Cash changes: category, budget and subscription are cleared; withdrawal destinations and the deposit source become Cash account. If an operation pauses, retry the selection; existing links are reused.
